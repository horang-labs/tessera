# Install the Tessera control skill explicitly

Tessera does not inject `tessera-cli` automatically into Claude Code, Codex, or OpenCode sessions. Following Orca's model, the user explicitly runs the standard Skills CLI command `npx skills add https://github.com/horang-labs/tessera --skill tessera-cli --global` in the selected Agent Environment and chooses the desired target in its interactive picker. The same reusable setup surface appears from onboarding and Settings, shows and copies the command, preloads it in an inline terminal without submitting it, and rescans when execution completes. The standard Skills CLI and its lock file are authoritative for discovery, freshness, target selection, update, conflict, and removal. Tessera never silently maintains the skill during provider launch. The skill remains optional and inert outside Tessera-managed sessions; absence, failure, or conflict never blocks a provider launch. Tessera refuses to overwrite or remove a copy whose source or locked contents no longer identify the Tessera installation.
