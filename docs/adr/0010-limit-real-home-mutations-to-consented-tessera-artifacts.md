# Limit real-home mutations to consented Tessera artifacts

Within a provider's real home, Tessera may own only its enabled-by-default Codex lifecycle hook and a `tessera-cli` skill the user explicitly installed through the standard Skills CLI. Authentication, MCP configuration, ordinary provider settings, history, and all other state remain owned by the provider or user and are neither managed nor migrated by Tessera. Hook ownership is recorded before mutation; skill ownership comes from the standard Skills CLI source and lock-backed content. Either artifact becoming externally modified stops further overwrite or removal. Deleting a Tessera-managed Session removes only Tessera's management record and does not delete the provider-owned conversation history; provider-history deletion remains a separate explicit feature. If provider history disappears independently, Tessera retains its management record but marks the Session unavailable for resume rather than restoring it from another copy or home.
