# Manage the Codex hook across the Tessera lifecycle

Agent status hooks are enabled by default. Tessera reconciles its owned lifecycle hook in the active authoritative Codex home without a separate first-install consent prompt, while preserving every user-owned hook and refusing to overwrite an externally modified Tessera artifact. Selecting another Agent Environment reconciles only the newly active home and does not remove the previous environment's hook. Outside a Tessera-managed Codex session, the installed hook is a complete no-op and neither connects to Tessera nor affects ordinary Codex behavior. Settings provides the Orca-style Agent status hooks toggle: turning it off removes the managed hook from the active home, records revocation, stops reconciliation, and clearly blocks only new Codex launches until enabled again. Removing Tessera removes its hooks from known homes while leaving user-owned hooks unchanged.
