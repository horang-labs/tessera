# Block Codex launch when the real-home hook is unavailable

Tessera launches Codex against the user's authoritative home and depends on its managed lifecycle hook to observe the session correctly. Agent status hooks are enabled by default: startup, Agent Environment changes, and Codex prelaunch reconcile an ordinarily absent or stale hook in the active environment and verify it through Codex's trust API. A pending launch continues once after successful preflight. If reconciliation or trust verification fails, Tessera blocks that Codex launch with structured recovery outside terminal output instead of falling back to a managed home or starting an unobserved session. If hook health is lost after a managed Codex Session has started, Tessera keeps that Session running in a degraded state but blocks new Codex launches and resumes until the hook is healthy again. This failure is isolated to Codex and does not block Claude Code or OpenCode sessions.
